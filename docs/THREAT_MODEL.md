# Threat Model

## Assets

- Client-local MalMem partitions and labels.
- Global model parameters and per-round client updates.
- Experiment metrics and saved model artifacts in `state/`.

## Adversaries

- Byzantine clients that submit poisoned or extreme updates.
- Honest-but-curious operators who can inspect metrics and global models.
- Network observers when mTLS is not enabled.
- Post-hoc tampering with metrics artifacts.

## Current Controls

- mTLS support for Flower client/server transport.
- Robust aggregation: median, trimmed mean, Krum, Bulyan, and median-of-means.
- FLANDERS-like update norm outlier filtering.
- Server-side update clipping and optional Gaussian server-DP noise.
- Sample-level DP for MLP via Opacus.
- Native CatBoost serialization instead of pickle.
- Metrics hash chain to make post-hoc tampering detectable.

## Explicit Non-Goals

- Production-grade secure aggregation is not implemented.
- Demo certificates generated by `certs/generate_certs.sh` are not production credentials.
- Sample-level DP does not replace formal client-level DP accounting.
