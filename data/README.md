# MalMem Dataset

This project expects `Obfuscated-MalMem2022.csv` at the repository root.

Source:
- CIC-MalMem-2022 dataset page: https://www.unb.ca/cic/datasets/malmem-2022.html
- Kaggle mirror with `Obfuscated-MalMem2022.csv`: https://www.kaggle.com/datasets/hasanccr92/cic-malmem-2022

Expected SHA256:

```text
624ecb6c9229cf62bd3b8f65d23a2b132760e6bada458aa46eee134a313840c4  Obfuscated-MalMem2022.csv
```

Use `make data` to download via the Kaggle CLI and verify the checksum. Kaggle requires credentials in `~/.kaggle/kaggle.json`.
